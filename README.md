# USDTF Web

Este projeto simula uma versão descentralizada e funcional do USDT (Tether), utilizando engenharia de espelho avançada.

## ✅ Recursos:

- Token com mesmo nome, símbolo e decimais que o USDT
- Total de **90 milhões de tokens**
- Aparece automaticamente na MetaMask
- Interface com botão para envio direto do token
- Conectado à rede real com contrato:
  `0xCf32ae001874CB755Ce60Cd32D177bc4EEE0dF2B`

## 🌐 Painel Online

O painel já está pronto e pode ser usado direto no Vercel:

👉 [Acessar Painel USDTF](https://usdtf-web22.vercel.app/) ← *(troque esse link pelo seu se estiver diferente)*

## 🧠 Tecnologias

- Solidity (ERC-20 Padrão)
- Web3.js
- HTML + JavaScript puro
- Deploy na Vercel
- MetaMask como carteira padrão

## ⚠️ Aviso

Este projeto é educacional e demonstra apenas técnicas de simulação com tokens espelhados.  
**Não representa o token real USDT emitido pela Tether.**
